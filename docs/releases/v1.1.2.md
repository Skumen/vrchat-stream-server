# v1.1.2 — исправлен молчаливый обрыв установки после «Запускаю MediaMTX»
🔧 **Исправление.** Всем, кто ставит или обновляет сервер, рекомендуется эта версия.

## Что было не так

Установка обрывалась без сообщения сразу после строки `==> Запускаю MediaMTX`. Фаервол не настраивался, HTTPS-сертификат не выпускался.

Причина: следующим шагом скрипт определяет порт SSH, чтобы не закрыть его фаерволом. Одна из проверок смотрела переменную `SSH_CONNECTION`, которую `sudo` убирает. Проверка возвращала «ложь», это значение становилось результатом всей функции, и `set -e` молча завершал скрипт. Ошибка была в версиях 1.0.2–1.1.1.

## Что исправлено

- **Порт SSH определяется надёжно**, в том числе под `sudo` и когда `sshd -T` не отвечает.
- **Ожидание обновлений apt** не обрывается, если на системе нет лога dpkg.
- **Неожиданная ошибка больше не завершает скрипт молча:** он пишет код, строку и команду, на которой остановился, и ссылку, куда сообщить.
- **Регрессионные тесты** на все три случая. На 1.1.1 они падают, на 1.1.2 проходят.

## Установка / обновление

```bash
curl -fsSL https://github.com/Skumen/vrchat-stream-server/releases/latest/download/setup.sh -o setup.sh
sudo DOMAIN=stream.example.com bash setup.sh
```

Ключ OBS, домен и остальные настройки сохраняются. При первом включении ufw держите открытой консоль (VNC) у провайдера.

---

**English:** fixed a silent abort right after "Запускаю MediaMTX" (versions 1.0.2–1.1.1). Detecting the SSH port relied on `SSH_CONNECTION`, which `sudo` removes; the failed check became the function's result and `set -e` quietly stopped the script before the firewall and HTTPS setup. Unexpected errors are now reported with the failing command instead of exiting silently.
