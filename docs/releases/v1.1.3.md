# v1.1.3: исправлена ошибка ufw «Invalid syntax» при установке
🔧 **Исправление.** Всем, кто ставит или обновляет сервер, рекомендуется эта версия.

## Что было не так

На шаге фаервола установка останавливалась с ошибкой:

```
ERROR: Invalid syntax
[x] Неожиданная ошибка (код 1) в строке 587: ufw allow "${p%%:*}" comment "${p#*:}" > /dev/null
```

В комментарии к правилу ufw для порта 80 был апостроф («Let's Encrypt»), а ufw не принимает кавычки в комментариях. ufw при этом ещё не был включён, так что доступ по SSH не затрагивался.

## Что исправлено

- **Комментарии правил ufw** — только буквы, цифры, пробелы и дефис.
- **Подставной `ufw` в тестах**, как настоящий, отвергает кавычки в комментариях. Тест фаервола теперь проверяет и код завершения: на 1.1.2 он падает, на 1.1.3 проходит.

## Установка / обновление

```bash
curl -fsSL https://github.com/Skumen/vrchat-stream-server/releases/latest/download/setup.sh -o setup.sh
sudo DOMAIN=stream.example.com bash setup.sh
```

Ключ OBS, домен и остальные настройки сохраняются. При первом включении ufw держите открытой консоль (VNC) у провайдера.

---

**English:** fixed `ERROR: Invalid syntax` from ufw during installation: a firewall rule comment contained an apostrophe ("Let's Encrypt"), which ufw rejects. The test mock now rejects quotes like the real ufw.
