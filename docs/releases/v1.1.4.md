🧪 **Тест полной установки** и исправление сообщения об ошибке конфига nginx.

## Что нового

- **Тест полной установки.** `setup.sh install` целиком, в отдельном процессе и как под `sudo` (без `SSH_CONNECTION`), с временной папкой вместо корня системы. Сценарии:
  - свежая VM (ufw и fail2ban не установлены, идут обновления системы);
  - повторный запуск: ключ и настройки сохраняются;
  - переход со старой установки на nginx-rtmp;
  - без домена, фаервола и fail2ban;
  - DNS не резолвится, Let's Encrypt отказал, ошибка в конфиге nginx;
  - удаление.

  Проверяются и порядок шагов (SSH разрешён до включения ufw, ufw включён до запроса сертификата), и получившиеся файлы. Страховка не даёт тесту записать что-либо за пределы временной папки. Именно такой тест поймал бы три ошибки версий 1.1.x.

## Исправлено

- **Ошибка в конфиге nginx.** Скрипт повторно запускал `nginx -t`, чтобы показать ошибку, и `set -e` обрывал его раньше понятного сообщения с путём к бэкапу. Теперь сообщение выводится. Ошибку нашёл новый тест.
- **Все системные пути** (`/etc/nginx`, `/etc/fstab`, бэкапы, лог nginx) вынесены в переменные в начале `setup.sh`.

## Установка / обновление

```bash
sudo vrc-stream update
```

Или с нуля:

```bash
curl -fsSL https://github.com/Skumen/vrchat-stream-server/releases/latest/download/setup.sh -o setup.sh
sudo DOMAIN=stream.example.com bash setup.sh
```

Fixed: an nginx config error now shows its message and backup path instead of stopping earlier.
