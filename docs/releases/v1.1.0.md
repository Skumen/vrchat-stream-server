# v1.1.0 — обновление одной командой, fail2ban, автотесты, English README
Сервер проверен в **VRChat на PC и на Quest**. Эта версия добавляет обновление одной командой, защиту ключа OBS и автоматическую проверку каждого изменения.

## Установка

На VM с Ubuntu 20.04+ или Debian 11+:

```bash
curl -fsSL https://github.com/Skumen/vrchat-stream-server/releases/latest/download/setup.sh -o setup.sh
sudo DOMAIN=stream.example.com bash setup.sh
```

**Обновление с 1.0.x:** скачайте `setup.sh` той же командой и запустите `sudo bash setup.sh`. Ключ OBS, домен и остальные настройки сохранятся. Дальше обновляться можно одной командой: `sudo vrc-stream update`.

## Что нового

### `vrc-stream update`
- `sudo vrc-stream update` — обновление до последнего релиза с GitHub.
- `vrc-stream update --check` — только проверить, есть ли новая версия.
- `sudo vrc-stream update v1.0.3` — конкретная версия, например для отката.

Перед установкой скрипт проверяет контрольную сумму из `SHA256SUMS.txt` и синтаксис. Подменённый или повреждённый файл не установится.

### fail2ban
- **Бан IP, подбирающих ключ OBS:** 20 неудачных попыток за 10 минут → бан на 30 минут. Правило мягкое специально: OBS с опечаткой в ключе переподключается каждые пару секунд.
- `sudo vrc-stream status` показывает заблокированных, `sudo vrc-stream unban <IP|all>` разбанивает.
- Заодно защищается SSH. На Debian 12 SSH-правило переключается на журнал systemd, без этого fail2ban там не запускается.
- Бан через ufw, если он включён. Выключить fail2ban: `FAIL2BAN=0`.

### Ожидание apt с прогрессом
Пока система ставит обновления, скрипт раз в 30 секунд пишет, сколько уже ждёт и какой процесс занял apt.

### Автотесты и GitHub Actions
- **Тесты в репозитории** (`tests/`): 200+ проверок.
  - Unit-тесты на подставных `ufw`, `apt-get`, `systemctl` и других системных командах.
  - Интеграционные тесты с настоящим MediaMTX: ключ OBS, HLS, RTSP, заставка, `status`.
  - Проверка фильтра fail2ban настоящим `fail2ban-regex`.
- **На каждый push:** ShellCheck и все тесты.
- **Релизы выпускаются автоматически:** тег → тесты → сборка файлов → публикация. Этот релиз опубликован именно так.
